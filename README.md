# Aivel Orga

Кандидатский бриф и контракт роли директора по маркетингу Aivel.

Страница фиксирует:

- контекст и порядок фокуса: СМБ → Enterprise → бух-аутсорс;
- функциональную модель маркетинга;
- целевую оргструктуру;
- границы с Продуктом, Коммерцией и M&A;
- метрики и двусторонний контракт CEO ↔ директор.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm run check
```

Публикация в GitHub Pages выполняется автоматически из `main`.
