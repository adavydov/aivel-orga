# Aivel Орга

Кандидатские брифы и контракты ключевых ролей Aivel.

Опубликованы две отдельные страницы:

- `/` — директор по маркетингу: машины спроса, целевая орга, границы и метрики;
- `/commercial/` — коммерческий директор: Inbound, Partners, Enterprise New
  Business, KAM, целевая орга, границы и метрики.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm run check
```

Публикация в GitHub Pages выполняется автоматически из `main`.
